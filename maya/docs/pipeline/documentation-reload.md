# Documentation and Reload

マニュアルを開き、開発中のYWTA Packageを再読み込みします。

## Documentation

### Reference

- **Menu:** `YWTA > Documentation`

設定された`DOCUMENTATION_ROOT`をWeb Browserで開きます。ローカルでは
[YWTA Maya Manual](../README.md)を参照してください。

## Reload YWTA

### Reference

- **Menu:** `YWTA > Reload YWTA`

読み込まれているYWTA Packageを再読み込みし、メニューを作り直します。

既存UIや古いModule参照が残る可能性があります。開発者向けの機能として、Sceneを保存してから
使用してください。
