# Reload and Resources

Python Moduleを再読み込みし、Maya標準のResource Browserを開きます。

## Reload All Modules

### Reference

- **Menu:** `YWTA > Utility > Reload All Modules`
- **Audience:** YWTA開発者

初期Snapshotより後に読み込まれたModuleを再読み込みします。名前に反して、すでに読み込まれた
全Moduleを対象にはしません。Reload中の例外も表示されません。

状態が不整合になった場合は、Mayaを再起動してください。

## Resource Browser

### Reference

- **Menu:** `YWTA > Utility > Resource Browser`

Maya標準のResource Browserを開きます。YWTA固有のResource管理機能ではありません。
